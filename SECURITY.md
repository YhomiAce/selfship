# Security Policy

This platform stores credentials that grant access to users' servers, so we take security reports seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Report vulnerabilities privately through GitHub's
"Report a vulnerability" button (Security tab), or by email to the maintainers.

Include steps to reproduce, the impact, and any suggested fix. We aim to acknowledge reports within 72 hours.

## Scope

How we handle SSH keys, environment variables and tokens is described in [docs/04-security.md](docs/04-security.md).
